# 🛍️ Customer Behaviour Analysis 📊
An end-to-end data analytics project that explores customer shopping behaviour using Python, SQL, and Power BI to uncover business insights and support data-driven decisions. 🚀

## 📌 Overview 

### This project analyzes retail transaction data to understand:
  👥 Customer behaviour<br>
  🛒 Product performance<br>
  🏷️ Discount impact<br>
  ⭐ Subscription trends<br>
  💰 Revenue patterns<br>

## 📂 Dataset 

📊 3,900 customer transactions<br>
📑 18 features<br>

Includes:<br>

Customer demographics (Age, Gender, Location)<br>
Purchase details (Products, Categories, Amount)<br>
Shopping behaviour (Discounts, Reviews, Shipping)<br>
<br>
🧹 Missing values were cleaned during preprocessing.<br>
<br>

## 📈 Key Insights
<br>
⭐ Subscribers generate higher revenue.<br>
🤝 Loyal customers are more likely to subscribe.<br>
🏷️ Discounts influence purchasing behaviour.<br>
👥 Certain age groups contribute more to sales.<br>
